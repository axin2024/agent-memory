# 跨会话智能体记忆服务｜开源项目说明与首个案例

**agent-memory** 是面向自托管的 Go 项目。提供与助手解耦的服务接口。MySQL 持有记忆、来源、版本和删除状态，检索副本可重建。 本页作为后续公开使用手册的需求稿，实际发行时补入测试版本、安装入口与已验证的依赖组合。

## 准备

两个助手、隔离租户、偏好修订对话与可回放检索集。

用户先说偏好邮件，后说改用短信；两个授权助手开启新会话查询，再由用户执行遗忘，重放旧来源同步。

## 第一次使用

1. 以用户身份分别授予两个演示助手记忆读写权，提交一次明确的邮件偏好。
2. 在第二次会话纠正为短信，查看新旧版本和来源，另建未授权租户检验隔离。
3. 在两个新会话执行同一召回，各自得到有效值和可见来源。
4. 用户执行遗忘，再回放最早来源并清空缓存重试，检查两个助手的召回和清理回执。

## 对照综合样例

返回短信及新来源，展示旧偏好已失效；删除后两个助手均不再召回，旧来源重放不能复活记录。 对照结果时保留源记录号、版本和操作时间，追踪从输入到最终交付的关联。

## 制造一次可恢复的异常

历史时点查询仍受当前可见权限限制。回到对象详情核对 recall_log 和审计记录，再按指定版本恢复或重试。确认相同操作不会生成两份有效结果。

## 自托管与反馈

恢复备份前重施删除水位，禁止从陈旧来源重新派生已遗忘事实；审计仅保留必要摘要。 提交问题请提供版本、最小合成输入、预期与实际结果。对接扩展可从以下方向开始：模型抽取、检索排序与助手 SDK；新策略须提交冲突、跨用户及遗忘评测。
