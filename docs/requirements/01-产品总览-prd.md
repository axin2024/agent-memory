# 跨会话智能体记忆服务｜产品总览

**正式需求基线 v2 · Go · 独立开源项目**

提供与助手解耦的服务接口。MySQL 持有记忆、来源、版本和删除状态，检索副本可重建。

## 使用者与责任边界

应用身份提交用户授权的会话，用户可查改删本人记忆，租户管理员配置保留期，审计员仅看最小操作摘要。

## 完整交付链路

应用与同意 → 来源写入 → 候选抽取 → 冲突与版本 → 召回与解释 → 删除与遗忘 → 用户工作台 → 质量与维护。

## 产品范围与里程碑

| 里程碑 | 能力 | 交付物或判断依据 |
|---|---|---|
| 基础数据与首笔业务 | 应用与同意、来源写入 | 重送同一轮会话只有一份来源记录。 |
| 贯通核心生产流程 | 候选抽取、冲突与版本、召回与解释 | 查询当前通知方式返回短信及修订来源。 |
| 异常、运营与独立交付 | 删除与遗忘、用户工作台、质量与维护 | 100 组样例可定位每条命中来源。 |

里程碑用于排开发顺序。首个完整公开版包含本项目全部 8 个业务域、24 项细分能力以及验收表的全部编号场景。

## 公开演示与成效

用户先说偏好邮件，后说改用短信；两个授权助手开启新会话查询，再由用户执行遗忘，重放旧来源同步。

返回短信及新来源，展示旧偏好已失效；删除后两个助手均不再召回，旧来源重放不能复活记录。

100 组跨会话对话测试冲突、新鲜度和删除，跨租户召回与已删除事实复现为零。以上为发布目标，验收报告须给出实测环境及原始记录。

## 边界与外部依据

恢复备份前重施删除水位，禁止从陈旧来源重新派生已遗忘事实；审计仅保留必要摘要。

接口和业务术语的参考材料见 [持久会话记忆项目](https://github.com/thedotmack/claude-mem)。具体范围由本项目的操作契约与验收用例界定。
