# 跨会话智能体记忆服务 2.0 产品需求文档

**团队知识记忆与可追溯共识**
需求评审版 · 2026-11-26 · 计划基线 v1.1.0（b63921d）

## 产品目标与交付边界

当前发行覆盖个人同意、来源抽取、事实版本和遗忘恢复。本版支持以下业务流程。项目组将已授权的个人经验提名为团队知识，双人评审并带来源发布，按项目权限召回，源撤回后传播到派生知识。 [项目说明](../../README.md) · [上一版业务需求](02-业务与交互-prd.md)

向量索引是可重建派生数据，原始证据和权限存在 MySQL。真实模型只处理被授权用于推理的片段。

## 使用者与工作台

作者提名，空间维护者分派评审，评审人确认来源，项目成员按目的查询，数据所有者可撤回。

作者预览将共享的每段文字，评审人从结论跳至出处。成员可查看生效范围与版本，撤回页先显示受影响条数，再跟踪查询层及索引的处理水位。

## 功能需求

下列六项均纳入正式版本。验收编号按项目独立，后文列出每项的触发条件和预期结果。

| 需求 | 模块 | 产品行为与约束 | 验收 |
| --- | --- | --- | --- |
| R1 | 团队空间 | 空间管理员定义成员、读写职责与项目目的，成员离开即撤销共享访问。 | A1、A2 |
| R2 | 知识提名 | 作者选择证据片段、用途和期限，预览对团队可见内容，可在发布前撤回。 | A3、A4 |
| R3 | 共识评审 | 模型归纳带逐句引证的草案，两位不同评审人处理冲突、标注适用条件和生效日。 | A5、A6 |
| R4 | 团队召回 | 先筛项目及用途，再混合关键词和向量召回，返回来源、版本、有效期与解释。 | A7、A8 |
| R5 | 依赖撤回 | 从来源追踪派生摘要，撤回即屏蔽，拥有其他证据的条目交由评审人重新证明。 | A9、A10 |
| R6 | 知识维护 | 维护者识别陈旧冲突和孤立证据，运行冻结问题集，对照引用、时效及隔离指标。 | A11、A12 |

## 页面操作与回执

| 关联需求 | 角色与入口 | 操作细节 | 需要读回的字段 |
| --- | --- | --- | --- |
| R1 · 团队空间 | 空间主管/授权面板 | 依项目目的分配成员角色并预览可导出范围 | space_id、policy_rev |
| R2 · 知识提名 | 作者/共享预览 | 选择来源片段、用途和截止日，保存可撤回提名 | nomination_id、grant_rev |
| R3 · 共识评审 | 知识评审人/证据并排视图 | 比对摘要与出处、标记矛盾、记录适用情景 | claim_rev、review_votes |
| R4 · 团队召回 | 项目成员/知识搜索 | 查看结论、来源和适用条件，按用途缩小范围 | claim_ids、citations |
| R5 · 依赖撤回 | 来源所有者/撤回影响页 | 查看派生条目清单并核对查询与索引水位 | withdrawal_seq、affected_claims |
| R6 · 知识维护 | 知识维护者/质量台 | 评估陈旧率、引用质量与隔离结果，分派复核 | evaluation_id、review_queue |

查询评测以问题、空间、用途、基准日期为一组，报告最前 5 条的有效引用率。撤回演练分别在索引更新前、更新后及旧备份恢复后查询，三次泄露计数均须为零。

## 状态、权限与数据

知识 提名→待双审→发布→过期或撤回，替代版关联旧版。撤回后的重发必须使用新授权和新审核。

引用图禁止闭环。检索和导出在返回前同时检查空间权限、原始授权及撤回水位。删除源正文后仅存允许保留的审计元数据。

MySQL 保存业务记录与操作回执。下列为新增逻辑对象和关键字段，所有归属组织的数据都须持有可校验的组织标识。

- `team_space(policy,owner)`
- `nomination(source_ref,grant_rev)`
- `claim_revision(valid_from,supersedes)`
- `evidence_edge(parent,child)`
- `withdrawal_watermark(space,seq)`

来源引用携带授权版本，索引键含空间和知识版本，后台重建先校验撤回水位。 写入前校验操作者对目标对象的权限与当前修订。详情、搜索、导出和后台重试按同一归属校验。保留决定者、请求号、前后状态、发生时间及关联证据编号。

## 核心接口与集成

主要写入入口为 `POST /team-spaces/{id}/claims`。请求必填字段为 `nomination_ids, evidence_spans, applicability, grant_revisions`。成功回执提供 claim_id, missing_grants, review_state。请求另带租户身份和幂等键。相同键及相同内容返回原业务编号，相同键对应不同内容返回 409。输入不满足业务约束时返回 422 和字段路径，身份无权限读取的跨租户对象返回 404。

需要异步处理时，接收事务同时写入业务记录与待处理事件，再返回 202 及回执查询地址。回读须显示当前状态、已完成步骤、上次失败原因和可重试条件。外部系统已受理但应答丢失时，按原请求身份核查实际结果。

### 合成请求与业务回执样例

请求体示例使用演练环境中的对象。带摘要的样例在开发验收时应替换为实际文件或参数的计算值。

```json
{
  "nomination_ids": [
    "N1"
  ],
  "evidence_spans": [
    {
      "source": "S1",
      "start": 0,
      "end": 12
    }
  ],
  "applicability": "project-A",
  "grant_revisions": [
    3
  ]
}
```

业务回执示例可由提交响应或后续状态查询取得。

```json
{
  "claim_id": "K1",
  "missing_grants": [],
  "review_state": "awaiting_review"
}
```

原授权已撤回时拒绝生成团队草案。审计仅记录授权版本与拒绝原因。

## 升级、部署与恢复

个人事实默认留在原用途范围。只有本人显式提名的版本进入团队审阅，迁移不批量复制历史正文。 在隔离副本运行迁移预检，输出记录数量、归属冲突和待处理编号。新增结构先部署，回填分批提交并保存游标，完成对账后按租户启用新入口。

演练时在首次成功写入新业务后中断进程，从检查点重启。核对来源授权水位、派生图、撤回日志和向量索引重建位置。需要退出试点时停收新请求，排空已受理操作并导出未决清单。涉及数据恢复时同时恢复数据库与关联证据，再核对外部已生效的动作。

## 编号验收用例

以下均为下一版待执行的验收条件。正常与异常场景使用隔离租户、固定时钟和可重置的合成数据。

| 编号 | 需求 | 操作与可观察结果 |
| --- | --- | --- |
| A1 | R1 · 团队空间 | 同一人员在甲组可编辑、乙组仅可查。 |
| A2 | R1 · 团队空间 | 离组后旧访问令牌不能下载历史导出。 |
| A3 | R2 · 知识提名 | 同一来源同版本两次提名返回原提名编号。 |
| A4 | R2 · 知识提名 | 包含无权转授的第三方片段时拒绝提交。 |
| A5 | R3 · 共识评审 | 矛盾经验按地区拆分条件后可分别发布。 |
| A6 | R3 · 共识评审 | 模型无证据的结论被标出且不能自动发布。 |
| A7 | R4 · 团队召回 | 同问题在两项目分别返回各自的操作决定。 |
| A8 | R4 · 团队召回 | 向量索引滞后时以权威权限和撤回水位再次过滤。 |
| A9 | R5 · 依赖撤回 | 撤回一源影响三个摘要，未依赖该源的知识仍可查。 |
| A10 | R5 · 依赖撤回 | 恢复旧备份时先追平撤回日志才开放搜索。 |
| A11 | R6 · 知识维护 | 替换过时知识后旧版本在历史查询中保留撤回标识。 |
| A12 | R6 · 知识维护 | 回放模型结果单独计数，停用模型时仍可走人工提名及关键词查询。 |
| A13 | 全流程 | 用 100 组未预录团队问题实跑嵌入或归纳后端，设置相邻项目同名事实和已撤回证据，对照关键词基线报告引用正确率、拒答与泄露次数。 |
| A14 | 容量与可靠性 | 10 万知识条目、1000 组多用户查询，召回 P95 ≤ 300 ms，未授权或已撤回引用返回零条。 |

负载报告须记录机器及依赖版本、预热和采样时长、成功数、拒绝数和超时数。验收人从工作台与业务记录两侧核对 A13，并附上原始输入、回执和最终状态。真实模型、人工判断和回放夹具分别出具结果，记录模型及权重版本、输入规模、失败样本与资源消耗。

### A13 召回评测

100 组固定为 50 组应答、25 组跨项目近邻、25 组已撤回。应答组前 5 条至少命中正确来源 45 组，其余两组只要返回受限证据即判失败。

## 分期交付

1. **空间授权与提名。** 交付可导入的样例和可读回的第一批业务对象，验证基础身份、归属及版本。
2. **证据评审与召回。** 串通参与角色和执行入口，演练并发、重复请求及部分成功后的恢复。
3. **级联撤回及恢复验证。** 完成全流程验收、容量实测和旧版升级。随开源发行提供中文配置、样例输入输出、备份恢复步骤及已知限制。
