# 跨会话智能体记忆服务｜验收与运营

## 前置条件

在独立 MySQL 中导入可重置样例并创建两组隔离身份。演示资源包括两个助手、隔离租户、偏好修订对话与可回放检索集。冻结版本、输入、机器和时钟设置，接口回放与真实依赖的结果分列。

## 综合验收

**输入**　用户先说偏好邮件，后说改用短信；两个授权助手开启新会话查询，再由用户执行遗忘，重放旧来源同步。

**通过条件**　返回短信及新来源，展示旧偏好已失效；删除后两个助手均不再召回，旧来源重放不能复活记录。

在提交成功和回执返回之间断开，再使用相同标识重试。验收人同时检查 MySQL、界面和外部回执，记录业务结果数、重试次数及仍待人工处理的对象。用其他租户重复查询、下载和导出，预期可见记录为零。

## 容量与可观测性

100 组跨会话对话测试冲突、新鲜度和删除，跨租户召回与已删除事实复现为零。 附测量持续时间、负载构成、热身与稳定窗口、资源上限和异常分类。演练前后的持久记录须能关联到同一个请求或运行。
